# Branding in this fork

Graphite's logo and interface icons are under the *Graphite Branding License*,
which allows them only in unmodified official builds. This fork ships none of
them. Everything in `branding/` is generated by `designer-branding/` and
committed:

- **Interface icons** — from [Material Design Icons](https://pictogrammers.com/library/mdi/)
  by Pictogrammers, `@mdi/svg` 7.4.47, **Apache License 2.0**
  (`LICENSE-pictogrammers.txt`). Which icon stands in for which Graphite icon
  name is listed in `designer-branding/icon_map.py`. Brand logos and
  deprecated icons are excluded by the generator.
- **Icons drawn for the fork** (mouse hints, stroke caps and joins, justify,
  zoom ratios, empty) and **the Designer logo** — `designer-branding/own_icons.py`,
  under the fork's licence (MIT OR Apache-2.0).

File names keep Graphite's (for example `graphite-logotype-solid.svg`) so the
frontend's imports do not change; the contents are ours.

`tools/cargo-run` skips downloading Graphite's branded assets when this file
is present in `branding/`.
